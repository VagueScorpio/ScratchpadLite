Scratchpad Lite - Bundled Font Licenses
======================================

This file is GENERATED. Do not edit it by hand.

build.ps1 regenerates it from whatever is in the fonts/ folder, reading each
font's name, version, license description and license URL straight out of its
name table, and its embedding permission out of its OS/2 fsType field.


Status
------

  The fonts/ folder holds no bundle yet, so there is nothing to list.

  The generator itself arrives in Phase 2, with the rest of the font system.
  Until then build.ps1 copies this file through unchanged and says so.


What the generated file will contain
-----------------------------------

  One entry per font family, with:

    Family name
    Faces found (regular, bold, italic, bold italic, and any others)
    Version
    License description, as the font itself states it
    License URL
    Embedding permission, from OS/2 fsType
    Source file, relative to fonts/

  And a flagged section at the end for anything that needs a human decision:

    * a font with no license text at all
    * a font whose license text restricts or forbids redistribution
    * a font whose embedding permission is Restricted or Bitmap-only, which
      matters for the optional font embedding in Phase 10
    * a font that could not be read

  Those flags are the point of the file: a bundled font that cannot legally
  travel with the app has to be found before a release, not after.


A note on committing fonts
--------------------------

The repository does not track the bundle: .gitignore keeps fonts/* out and
keeps only fonts/README.txt. Two reasons, either of which is enough on its own.
A large bundle does not belong in git, and some font licenses forbid posting the
files publicly at all.
